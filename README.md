# VyomaVeera.V-1
VyomaVeera.V-1 or VyomaVeera Version 1 is a 3 degree of freedom aerial manipulator.

## Installation of Q-Ground Control

Following commands help us install the QGC app image and then run it on our system. 

```bash 
cd ~/Desktop

wget https://github.com/mavlink/qgroundcontrol/releases/download/v5.0.8/QGroundControl-x86_64.AppImage

chmod +x QGroundControl-x86_64.AppImage

./QGroundControl-x86_64.AppImage
```
